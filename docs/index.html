Install the skills

Choose one installation method. The skills.sh collection supports Claude Code, Codex and other compatible agents.

With skills.sh

npx skills@latest add davejrich/skills

As a Claude Code plugin

/plugin marketplace add davejrich/skills
/plugin install davejrich-skills@davejrich

Then supply your document or text and ask for /seven-hats or /six-frames.

Seven Hats includes a Python report renderer. Reading PDF and Word sources depends on your agent's available document tools. See the repository instructions for manual installation.
